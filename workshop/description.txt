Ancient Affection Compatibility Patch

Ancient Affection (원작자: nagis)의 Slay the Spire 2 v0.113.1 호환 패치입니다.
원본 모드와 함께 구독하는 추가 패치이며, 원본을 구독 해제할 필요가 없습니다.

사용 방법
1. 원본 Ancient Affection, BaseLib, RitsuLib과 이 패치를 함께 구독하고 활성화하세요.
2. 게임의 모드 로딩 순서에서 이 패치를 Ancient Affection보다 위에 배치하세요.
3. 게임을 재시작하세요. 멀티플레이 참가자 전원이 같은 게임·패치·의존 모드 버전을 사용해야 합니다.

지원 버전: 게임 v0.113.1, 검증한 원본 Ancient Affection v0.1.0.
원본 DLL을 시작 시 메모리에서 교정합니다. 원본 파일을 덮어쓰거나 설치 프로그램을 실행할 필요가 없습니다.
이미 설치한 별도의 원본 대체본이 있다면 중복 활성화하지 마세요.

수정 내용
- 강화 장갑 및 상인 오류를 일으키는 구버전 함수 호출 수정
- 고대인 강화 유물 선택지에 사용하는 플레이어별 호감도 정보 동기화
- 강화 유물의 비전투 보상 난수를 플레이어별로 분리
- 은 도가니, 날개 장화, 거대한 두루마리 출현 조건 복원
- 만화경 선택지 수와 다른 캐릭터 카드 재추첨 수정
- 장난감 상자: 밀랍 유물 3개 중 1개 선택을 4회

원작자를 존중하여 모든 언어의 설명문과 원본 이미지는 그대로 사용합니다.
유리 눈은 원래의 보상 5개/각 3장 구성을 유지합니다.
대표 이미지는 패치 제작 요청자가 직접 그린 원본 그림입니다.

검증 범위
원본 타입 614개, 메서드 2,462개, 추가 유물 173개와 주요 보상·장갑·상인·플레이어 선택 동기화를 자동 검증했습니다.
실제 두 PC의 멀티플레이, Godot 화면과 중도 저장/재접속은 아직 검증하지 않았습니다.

Original author: nagis. This is an unofficial compatibility add-on.
Keep the original Ancient Affection subscription enabled. Requires BaseLib and RitsuLib.
Place this patch ABOVE Ancient Affection in the game's mod load order, then restart.
Supports game v0.113.1 and the reviewed original v0.1.0 DLL. Original files and localization are untouched.
All multiplayer participants need matching mod versions. Live two-PC multiplayer and save/rejoin remain untested.
